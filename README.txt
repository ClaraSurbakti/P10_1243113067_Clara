CLARA CLAUDIA SURBAKTI — MULTI-PAGE PORTFOLIO WEBSITE

START HERE
1. Extract all files into one folder.
2. Open index.html in a browser.
3. The website opens in English by default. Use the fixed language button at the bottom-right to switch to Bahasa Indonesia, and click again to return to English.
4. To show your portrait, place your image in this folder and name it exactly: ProfileImage.jpeg

PAGES
- index.html — Home
- about.html — Personal profile and interests
- education.html — Education
- skills.html — Skills overview
- hard-skills.html — Practical / hard skills
- soft-skills.html — Soft skills
- tools.html — Tools and software
- experience.html — Experience
- portfolio.html — Portfolio highlights
- contact.html — Contact form

IMPORTANT
Keep all HTML files, styles.css, and script.js together in the same folder. The contact form prepares an email in the visitor's default email application; it does not send automatically. Replace the LinkedIn URL or portrait if needed.

LANGUAGES
English is the default language. The language toggle translates the site's visible page text, navigation, headings, descriptions, buttons, and form labels into Bahasa Indonesia. The toggle preference is remembered for the current browser session.
